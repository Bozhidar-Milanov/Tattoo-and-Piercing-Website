# Tattoo-and-Piercing-Website
Modern and responsive tattoo &amp; piercing studio website featuring a stylish gallery, tattoo and piercing designs, an About Us section, and contact information.

## 📌 Project Overview

This is a modern and responsive tattoo & piercing studio website built with **HTML, CSS, and JavaScript**. **Node.js** was used as part of the project environment for dependency management, development tooling, and running the application locally.

### ✨ Features

* **Home** – modern landing section introducing the studio.
* **Tattoos** – information about tattoo services and styles.
* **Tattoo Gallery** – visual gallery showcasing different tattoo designs and work.
* **Piercings** – information about available piercing services.
* **Piercing Gallery** – visual showcase of different piercing work.
* **About Us** – information about the studio and its services.
* **Contact** – contact details and an embedded **Google Maps** location pointing directly to the studio.
* **Google Reviews** – real customer reviews integrated from Google, allowing visitors to see authentic feedback about the studio.

### 🛠️ Technologies

* **HTML5** – website structure and semantic content.
* **CSS3** – styling, animations, layout, and responsive design.
* **JavaScript** – interactive elements and website functionality.
* **Node.js** – project environment, dependency management, and local development.

### 📱 Responsive Design

The website is fully responsive and optimized for **desktop, tablet, and mobile devices**, providing a consistent and user-friendly experience across different screen sizes.
